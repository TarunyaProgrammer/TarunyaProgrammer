## ⚡ Engineering Philosophy

My approach to software engineering is grounded in three principles:

1.  **Performance is a Feature**: Optimized rendering cycles, minimal bundle sizes, and efficient database queries are non-negotiable.
2.  **Clean Architecture**: Separation of concerns. Code should be readable, testable, and maintainable.
3.  **System-First Thinking**: Understanding how a single API call affects the entire system, from the load balancer to the database lock.
